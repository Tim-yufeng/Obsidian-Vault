### 展示一级目录的全部内容

- ls directory （省略directory即默认当前目录）
- ls -l ：以长格式展示（包含 user, group, 时间，权限等信息）
- ls -a：会展示隐藏文件 （Linux的隐藏文件都以一个点开头）
- 选项可以合并，如 ls -l -a 和 ls -la 是等价的

**Long format 信息解读：**

### I/O Redirection
Standard output 通常指电脑屏幕，而如果要修改这一output，可以用 '>'
<span class="green"> 本来应该输出到屏幕的内容，输出到指定地方 </span>
比如 ls -l > ls_rst.txt 就可以把本应输出到屏幕的  ls -l 内容输入到 这个叫 ls_rst.txt 的文件内

相应的，我们也有 Standard Input，通常指键盘，要修改这一input，可以用 '>'
<span class="green"> 本来应该等待键盘输入，现在从指定的地方（某个文件）获取输入 </span>
比如 my_add < input.txt，代表 my_add 这个程序从input.txt获取它的输入
（如果你在开发一个程序（比如 `my_add`），每次测试都要手动在键盘上敲数字会很麻烦。你可以提前把测试用的数字（比如多组数据）写在 `input.txt` 文件里，然后直接用 `<` 运行程序，就能快速看到结果，省去了每次手动输入的麻烦。）
