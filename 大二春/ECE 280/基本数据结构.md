## 线性表与栈 (Linear List & Stack)

### 1. 线性表 (Linear List)
* **特点**：零个或多个元素的有限序列，允许重复元素。支持**按位置**（索引）进行插入和删除。
* **基本方法**：
    * `insert(i, v)`: 在位置 i 插入值 v。
    * `remove(i)`: 移除位置 i 的元素。
    * `get(i)` / `set(i, v)`: 获取或修改位置 i 的值。

* **实现方式**：
    * **Array**：利用索引随机访问速度快（O(1)），但插入和删除需要移动大量元素（O(N)）。
    * **Linked List**：动态分配空间，插入删除操作只需修改指针，但访问特定位置需要从头遍历（O(N)）。
* **简要示例 (数组插入)**：
```cpp
void insert(int i, int v) {
	for (int j = numElts; j > i; j--) elts[j] = elts[j-1]; // 后移
	elts[i] = v;
	numElts++;
}
```
* **应用**：通用数据存储，适用于位置关系固定的场景。

### 2. 栈 (Stack)
* **特点**：**后进先出 (LIFO)** 的受限线性表。仅允许在表的一端（栈顶 Top）进行操作。
* **基本方法**：
    * `size()` 返回栈中元素个数。
    * `isEmpty()`: 检查是否为空。
    * `pop()`: 弹出（删除）栈顶元素，如果栈是空的，throw `stackEmpty`。
    * `Object &top()`: 返回栈顶元素的引用。
    * `push(Object o)`: 压入元素到栈顶。
* **实现方式**：
    * **数组**：实时记录数组的大小 `int size`，栈顶是数组的末尾，必要时需要动态给数组扩容

- **链表**：以链表头部（first）为栈顶，其他都很容易理解。

![[Pasted image 20260424145425.png]]

要注意的是，对于链表来说，需要专门写一个计算链表长度的函数：

```cpp
int LinkedList::size() {
	int count = 0; 
	node *current = first; 
	while(current){ 
		count++; 
		current = current->next; 
	} 
	return count;
}
```
或者也可以单独用一个 `size` 作为类成员，记录链表的长度。

* **应用**：括号匹配、函数调用栈（递归）、浏览器后退功能。

## 队列与双端队列 (Queue & Deque)

### 1. 队列 (Queue)
* **特点**：**先进先出 (FIFO)** 的受限线性表。在一端（队尾 Rear）插入，另一端（队头 Front）删除。
* **基本方法**：
	* `size()` : 返回队列的元素个数
	* `isEmpty()`：检查是否为空
    * `enqueue(v)`: 从末尾增加元素。
    * `dequeue()`: 从队头移走元素，如果队列为空，throw `queueEmpty`。
    * `Object &front()`: 获取队头元素引用。
    * `Object &rear()`：获取队尾元素引用。
* **实现方式**：
    * **普通数组**：会导致“假满”现象（前段空间浪费）。
    * **循环数组**：利用取模运算 `(i + 1) % capacity` 让数组首尾相连。  
    * 数组实现 Queue 的方法比链表复杂得多，其用途主要在Python，Java等不支持指针的语言中，具体见 [[Array for Queue]]
    * **链表**：使用带尾指针（last）的单向链表（Double-ended singly-linked list）。**从头出队，从尾入队**。

* **应用**：打印机任务管理、Web服务器请求处理、CPU进程调度。

### 2. 双端队列 (Deque)
* **特点**：栈与队列的结合体。允许在**两端**同时进行插入和删除操作。
* **基本方法**：
    * `push_front` / `push_back`
    * `pop_front` / `pop_back`
* **实现方式**：
    * **双向链表**：最理想的实现方式，所有端点操作均为 O(1)。
    * **循环数组**：需要同时支持索引的自增和自减取模。
* **应用**：需要在两端高效存取数据的缓冲区。

### **易错点提醒**
* **线性表越界**：操作前必须检查索引 `i` 是否在 `[0, size]` 范围内，否则应抛出异常。
* **栈/队列空状态**：执行 `pop` 或 `dequeue` 前务必调用 `isEmpty()` 检查，防止空指针或数组越界。
* **循环数组判满**：在循环数组中，通常需要一个额外的 `count` 变量或留出一个空位来区分“队空”和“队满”状态。
* **内存泄漏**：在链表实现中，执行 `pop` 或 `dequeue` 后必须手动 `delete` 被移除的节点。
