### 1. 基本概念
* **定义**：允许为类对象重新定义标准运算符（如 `+`, `-`, `*`, `<<` 等）的含义。
* **本质**：运算符重载是具有特殊名称的**函数**：关键字 `operator` 后接运算符符号。
* **优点**：使类对象的操作直观、易读，代码风格更接近内置类型（如 `int`）。

---

### 2. 重载规则与限制
* **不可创建新运算符**：只能重载已有的 C++ 运算符（不能造一个 `**` 表示幂运算）。
* **优先级与结合性不变**：重载后，运算符的计算先后顺序及结合方向保持原样。
* **操作数数量不变**：一元运算符（unary）重载后仍是一元，二元（binary）仍是二元。
* **内置类型限制**：不能重载仅包含内置类型（如 `int + int`）的运算符，**至少有一个操作数必须是类类型**。

---

### 3. 成员函数 vs. 非成员函数重载
* **成员函数重载**：
    * 左操作数必须是该类的对象，这是默认的。
    * 参数列表比实际操作数**少一个**（左操作数由隐含的 `this` 指针代表）。
    * **必须是成员**的运算符：`=`、`[]`、`()`、`->`。
* **非成员函数重载**：
    * 通常定义为 **友元 (friend)** 以便访问私有成员。
    * 左操作数可以不是该类对象（如 `2 + ComplexObject`）。
    * **建议**：对称性运算符（如 `+`, `-`, `==`）通常定义为非成员函数，以支持混合类型运算。

---

### 4. 友元 (Friendship) 
* **作用**：允许特定的非成员函数或类访问另一个类的 **private** 和 **protected** 成员。
* **语法**：在类定义内部使用 `friend` 关键字声明，==但友元**不是**该类==的成员。
* **特性**：友元关系不可传递，也不可继承。

```cpp
// 方式1：用成员函数
class A {
    int val;
public:
    A(int v) : val(v) {}
    A operator+(const A &r) const { return A(val + r.val); }
};

// 方式2：用非成员友元函数
class A {
    int val;
public:
    A(int v) : val(v) {}
    friend A operator+(const A &l, const A &r);
};

A operator+(const A &l, const A &r) {
    return A(l.val + r.val);
}
```

### 5. 常用运算符重载详解

#### **(1) 赋值运算符 (=)**
* 必须定义为成员函数。
* 需处理**深拷贝**、**自我赋值检查**以及**返回 `*this` 的引用**。

#### **(2) 下标运算符 (`[]`)**
* 用于访问容器类（如 `IntSet`, `List`）的元素。
* 通常需要提供两个版本：
    1.  **非 const 版本**：`T& operator[](int index);`（允许修改元素）。
    2.  **const 版本**：`const T& operator[](int index) const;`（只读访问）。

#### **(3) 输出运算符 (<<)**
* **必须定义为非成员函数**（通常是友元），因为左操作数是 `ostream&` 而非类对象。
* **语法规范**：
    ```cpp
    ostream &operator<<(ostream &os, const MyClass &obj) {
        os << obj.data;
        return os; // 必须返回引用以支持链式调用 cout << a << b;
    }
    ```


#### **(4) 输入运算符 (>>)**
* 必须定义为非成员函数。
* 第二个参数必须是**非 const 引用**（因为要向对象写入数据）。
* 需要处理输入失败的情况（检查 `istream` 的状态）。

---

### 6. 易错点与避坑指南
* **返回类型选择**：
    * 算术运算符（如 `+`）通常返回**新对象（值返回）**，不建议返回引用。
    * 赋值与复合赋值（如 `=`, `+=`）必须返回**左操作数的引用**。
* **const 准确性**：不改变对象状态的运算符（如 `query`, `size`, `[]` 的读取版）务必加上 `const` 修饰。
* **逻辑一致性**：重载 `+` 后，通常也应重载 `+=`，且两者逻辑应保持一致。
* **自增/自减 (++/--)**：
    * 前置版本：`T& operator++();`（返回增加后的引用）。
    * 后置版本：`T operator++(int);`（带一个 dummy `int` 参数区分，返回增加前的副本）。
