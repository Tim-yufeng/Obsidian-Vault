## 动态内存分配与析构函数 (Dynamic Memory & Destructor)

### 1. 内存分配的三种形式
* **全局变量**：程序启动前分配，直到程序结束才释放。
* **局部变量（栈 Stack）**：进入函数或代码块时分配，退出时自动销毁。
* **动态分配（堆 Heap）**：
    * **需求**：当数据大小（如集合容量）在编译时无法确定，或者需要跨函数生存周期时使用。
    * **操作**：由程序员手动控制分配与释放。

---

### 2. C++ 动态内存操作：new 与 delete
* **new 运算符**：
    * 从堆中申请空间并返回该类型的**指针**。
    * 例子：`int *p = new int;` 分配一个整数；`int *arr = new int[50];` 分配 50 个整数的数组。
* **delete 运算符**：
    * 释放指针指向的堆空间。
    * 释放数组必须使用 **`delete[]`**，否则会导致内存泄漏。
* **悬空指针 (Dangling Pointer)**：对已 `delete` 的指针再次访问或删除是严重错误。

### 3. 构造函数的进阶用法
* **函数重载 (Overloading)**：同一个类可以有多个同名构造函数，只要参数列表不同。
* **默认参数 (Default Arguments)**：
    * 在声明中指定初始值：`IntSet(int size = 100);`。
    * **规则**：默认参数必须从右向左连续排列。
* **成员初始化列表**：推荐在构造函数中使用冒号语法初始化成员，效率更高。

---

### 4. 析构函数 (Destructor)
* **定义**：类名前加波浪号，如 `~IntSet();`。
* **特性**：
    * ==没有返回类型，没有参数==。
    * ==一个类只能有一个析构函数==。
* **触发时机**（两种情况）：
    1. 局部对象离开作用域。
    2. 对对象指针调用 `delete`。
* **核心职责**：释放对象在生命周期内申请的**外部资源**（如 `new` 出来的动态数组）。

### 5. 动态数组类 (Dynamic IntSet) 的实现逻辑
* **数据成员**：不再使用固定大小数组，而是改为 `int *elts;` 指针，并增加 `int sizeElts;` 记录当前总容量。
* **构造函数**：根据传入的 `capacity` 执行 `elts = new int[capacity];`。
* **析构函数**：执行 `delete[] elts;` 防止内存泄漏。
* **比喻**：构造函数是“领证入场”，分配座位（空间）；析构函数是“退场清算”，必须归还座位，否则剧场（内存）会满员。

---

### 总结与易错点检查
* **成对原则**：每一个 `new` 必须对应一个 `delete`，每一个 `new[]` 必须对应一个 `delete[]`。
* **内存泄漏 (Memory Leak)**：如果丢失了指向堆空间的指针而未释放，该内存将无法再被利用。
* **自动生成的析构函数**：如果类成员只是简单类型，默认析构函数足够；如果含有**指针成员指向动态内存**，必须手动写析构函数。
* **delete 指针 vs delete 对象**：对普通对象不需要手动 delete；仅对 `new` 出来的指针才需要 delete。
