1. 空格问题
2. 头文件包含顺序：
	1. 直接的头文件，比如 p3.cpp 的直接头文件是 p3.h
	2.  **C 系统头文件**：例如 `<cstdio>`, `<cstdlib>`。
	3. **C++ 系统头文件**：例如 `<iostream>`, `<string>
	4. **其他库的 .h 文件**。
3. `main()` 函数内如果涉及 `try-catch` ，需要有一个 default catch `catch(...)` 来兜底一切可能的错误或恶意输入
4. 少用 `>> std::endl` 换行，改用 `'\n'` 
5. 能声明 `const` 的变量，别忘了声明，包括函数形参也是
6. 定义 `int` 变量记得初始化一个值，`std::string` 就不需要
7. 我们不说`str[i]` ，我们说 `str.at(1)`
