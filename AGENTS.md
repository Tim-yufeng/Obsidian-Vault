# Obsidian Vault Repository Rules

- This repository is the user's real Obsidian Vault and contains user-authored historical notes. It is a production environment, not the style-learning corpus.
- Use `personal-study-notes` when the requested artifact creates, extends, or substantially rewrites university course notes.
- Do not invoke that Skill for ordinary tutoring, homework solving, quiz answering, or calculation checks unless the user requests a note artifact.
- Never scan unrelated historical notes for style. Access only files necessary for the current task.
- Never delete, move, rename, reorganize, or mass-format historical notes or attachments.
- `All Images/` is the attachment directory; never overwrite or rename existing attachments.
- `*.generated.md` is generated output and must not be manually edited.
- Preserve unrelated existing Git changes. Global Git inspection may expose status and filenames only; inspect diff content only for authorized files.
- Do not create separate reflection notes unless explicitly requested.
