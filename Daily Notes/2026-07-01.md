1. **基础型（几何级数）：**
    

$\sum_{n=0}^{\infty} \alpha^n x^n = \frac{1}{1 - \alpha x}$


2. **乘了 nn（对 xx 求导一次，再乘 xx）：**
    

$\sum_{n=0}^{\infty} n \alpha^n x^n = \frac{\alpha x}{(1 - \alpha x)^2}$  


3. **乘了 n2n2（对 xx 求导两次，再调整系数）：**
    

$\sum_{n=0}^{\infty} n^2 \alpha^n x^n = \frac{\alpha x (1 + \alpha x)}{(1 - \alpha x)^3}$  

$A(x) = \sum_{n=0}^{\infty} \left( \frac{(e^{i\omega})^n + (e^{-i\omega})^n}{2} \right) x^n = \frac{1}{2} \left( \frac{1}{1 - e^{i\omega}x} + \frac{1}{1 - e^{-i\omega}x} \right)$
