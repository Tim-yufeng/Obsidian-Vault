# 10 I/O Streams

上一节建立了 stream 的模型并看了 cout / cin。这一节把这个模型推广到另外两个数据来源和目的地：file 与 string。三条内容其实只有一组接口——插入运算符、提取运算符、`getline()`、`str()`——换的只是连接的端点。

## 为什么还要 file stream

文件让数据可以永久保存：输出到文件的数据在程序结束后依然存在；输入文件可以反复使用，测试时不必一遍遍重新敲数据。file stream 就是文件与程序之间的 I/O 通道。

既然 Linux 已经有 I/O redirection，为什么还需要 file stream？一个直接的理由是需要同时写两个文件——重定向只能把标准输出整体改向一个地方。

## 使用 file stream

```cpp
#include <fstream>

ifstream iFile;   // 输入文件流对象
ofstream oFile;   // 输出文件流对象
```

stream 对象必须先与文件建立连接，这个动作叫打开文件：`iFile.open("myText.txt");`。这里有个版本差异：<span class="red">C++98 中 `open()` 只接受 C-style string，不能直接传 C++ string，需要用 `c_str()` 转换；C++11 起可以直接传 C++ string</span>。

连接好之后，用法与 cin / cout 完全对应：输入文件流用提取运算符和 `getline()`，`iFile >> bar;`、`getline(iFile, baz);`；输出文件流用插入运算符，`oFile << bar;`。

用完文件应当关闭：`file_stream.close();`，它断开 stream 与文件的连接。关闭的理由有两个：降低程序异常终止时文件被损坏的可能；如果程序之后要从这个输出文件里读数据，那么先关闭输出文件是必须的。如果忘了关闭，只要程序正常结束，系统会自动关闭文件，但仍然推荐显式关闭。

一个完整的读文件例子：

```cpp
#include <iostream>
#include <fstream>
using namespace std;
void main() {
    ifstream iFile;
    int bar;
    iFile.open("foo");
    iFile >> bar;
    cout << "The answer is " << bar << ".\n";
    iFile.close();
}
```

它把名为 `foo` 的文件以读取方式打开并与 `iFile` 关联，之后就可以像用 `cin` 那样从文件提取输入。若 `foo` 中的内容是 `42`，程序输出 `The answer is 42.`。

## 失败的 file stream 与读循环

file stream 在两种情况下进入 failed state：文件无法打开；试图读过文件末尾。状态检查方式与 cin 一致，`if (iFile) { ... }`，失败时返回 `false`。因此打开文件后应立即检查：

```cpp
iFile.open("a.txt");
if (!iFile) {
    cerr << "Cannot open a.txt\n";
    return -1;
}
```

读文件时有一个常见的坑，写成这样是错的：

```cpp
while (iFile) {
    getline(iFile, line);
    cout << line << endl;   // Why not good?
}
```

`getline` 读完一整行后，`iFile` 指向下一行的开头；读完最后一行后，`iFile` 指向文件末尾之前的位置（可以把文件末尾想成一个特殊字符），此时 <span class="red">`iFile` 仍然是 good 状态</span>，于是循环又执行一次 `getline`，而这一次什么也没读到，程序就多打印一个空行；要到再下一次循环，`iFile` 才越过文件末尾并使循环终止。

两种改法。第一种是在打印前再检查一次状态：

```cpp
while (iFile) {
    getline(iFile, line);
    if (iFile) {           // 刚才的 getline 是否成功
        cout << line << endl;
    }
}
```

第二种更简洁，也是更好的写法，直接把 `getline` 放进循环条件：

```cpp
while (getline(iFile, line)) {
    cout << line << endl;
}
```

它之所以可行，是因为 `getline` 的签名是 `istream& getline(istream& is, string& str);`，返回值就是它的参数 `is`（值是执行完当前 `getline` 之后的状态），所以循环条件等价于"上一次读取是否成功"。

## String stream

有些数据在到达程序时已经不是 stream 而是 string。两个典型场景：用 `getline()` 从文件读回一整行存进 string，而这一行里是一个 int 后跟一个 double，需要从 string 里把两个数读出来；或者手里有书名（string）和出版年份（int），需要拼成一个 string，其中要把 int 转成 string。

C++ 在 `sstream` 库中定义 string stream，分输入与输出两种：

```cpp
#include <sstream>

istringstream iStream;
ostringstream oStream;
```

input string stream 通常先指定它要读取的 string：`iStream.str(a_string);`，然后用提取运算符取出数据：

```cpp
istringstream iStream;
int foo;
double bar;
iStream.str(line);      // 若 line 是 "42 3.14"
iStream >> foo >> bar;  // 则 foo = 42; bar = 3.14;
```

output string stream 用插入运算符写入字符，它知道如何把标准数据类型转成字符并插入 string，最后用成员函数 `str(void)` 取出结果：

```cpp
int foo = 512;
int bar = 1024;
string result;
ostringstream oStream;
oStream << foo << " " << bar;
result = oStream.str();   // result 是 "512 1024"
```

这里 `<<` 承担的作用正好是 `atoi` 的反面：把数值的字符串表示造出来，而不是把字符串解析成数值。一个常见应用是格式化输出——手上是一组数值，但需要它们的字符串形式。

## 练习

给定数据文件格式如下，写一个程序读入全部数据并求总花费：

```text
apple 42
banana 25
carrot 33
```

每条记录是一个名字后跟一个数字，用 `getline` 逐行读入再交给 `istringstream` 解析，就能逐条累加，这正是 string stream 最常见的用途。
