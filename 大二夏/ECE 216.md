### Some Basic Definitions

**Signal**：随时间或空间（或其他独立的变量）变化的物理量
**System**：对信号进行操作的物理“装置”
**Signal Processing**：接受某些输入信号，产生某些相关的输出信号

从数学角度，信号是一个单变量或多变量的函数
由函数自变量的个数，可以对信号进行分类，这一分类标准称为 **Dimensionality**，即信号的“维度”
- **One-dimensional signal**：信号函数只有一个自变量
- **M-dimensional signal**：信号函数有 M 个独立的自变量

<span class="green"> 举个例子，BW TV（黑白电视）的图像就是一个可以表示为 I(x, y, t) 的函数，x, y, t 分别代表屏幕上的横纵坐标和时间，它有3个独立的自变量，因此是一个 3D signal </span>

另一种给信号分类的方式就是函数值的维度，我们知道函数值可以是一个数值（scalar），也可以是一个向量（vector）

- **Scalar** or **Single-channel signal**：函数值是实数或复数值
- **Multichannel signal**：函数值是实数或复数向量

<span class="green"> 还是电视机的例子，对于黑白电视，其函数值是 scalar；对于彩色电视机，其函数值是三维向量，因为彩色图片是由红绿蓝三色构成 </span>

还有一种分类方式称为 **time characteristics**，根据自变量的连续与否：
- **Continuous-time signal** or **Analog signal**：A function defined for all times $t\in (-\infty, \infty)$, or at least over some continuous interval $(a, b)$.
- **Discrete-time signal**：A function defined only at certain specific values of time.

类似的一种分类方式叫 **value characteristics**，根据函数值的连续与否：
- **Continuous-valued signal** or **Continuous-amplitude signal**：能在一个连续区间上取任何值
- **Discrete-time signal** or **Discrete-amplitude signal**：只能取一系列离散的值

还有一种分类方式是根据信号是否可预测，可以用一个数学表达式进行表示：
- **Deterministic signals**：Can be described by an explicit mathematical representation.
- **Random signals**：Evolve over time in an unpredictable manner.

### Transformations of CT signals

这又可以分为：
- Time transformations：就是对自变量的各种变换，包括平移，数乘（伸缩），等等
- Amplitude transformations：就是对因变量的变换，对波长进行反转，缩放等操作
- More signal operations：包括微分积分等等
- 两个信号参与运算

首先第一个，Time transformations，其实就是初中数学函数题，要注意的就是当伸缩和平移混合在一起的时候，先做哪个是有一点讲究的
比如对于信号：$y(t)=x(t)$, 给他变换为以下形式：
1. $y(t)=x(at-b)$ ，这时先平移 $b$，然后伸缩 $a$
2. $y(t)=x\left( \frac{t-t_{0}}{w} \right)$ , 这时先伸缩 $\frac{1}{w}$, 然后平移
（记忆的小技巧，按照把这坨式子拆回 $t$ 的顺序，去变换）

### Signal Characteristics

主要是辨析三个概念：信号的 average value, energy, average power.
简单来说：
- average value：直接对信号函数积分
- energy：信号的模平方的积分
- average power：对 energy 关于时间 average 一下

![[Pasted image 20260519213742.png]]
![[Pasted image 20260519213755.png]]

注意，average value = 0 不一定说明 $\int_{-\infty}^{\infty}x(t) dt$ 这个积分是有限的，只能说明它的增长速度慢于 T，并且奇函数的 average value 一定是0

更进一步的，我们定义：
- 如果 $0<P<\infty$, 那么 $E$ 一定是 infinite 的，我们称该信号是 ==power signal ==
- 如果 $E<\infty$, 那么 $P$ 一定是零，我们称该信号是 ==energy signal==
- 有些信号二者皆不是，比如 $x(t) =t^2$ , $E=\infty, P=\infty$，这种信号在工程中应用很少
