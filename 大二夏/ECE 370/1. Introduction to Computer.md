注意 software 和 hardware 的区别，一台计算机由三部分构成：
1. Hardware
2. System software（操作系统），由 C 语言和部分 Assembly 写成
3. Application software，由更高级的语言写成

![[Pasted image 20260512183114.png]]
Assembly 作为介于高级语言和机器语言之间的语言，起到了承接这二者的作用，后者就是纯粹的0和1
Assembly（汇编语言）通过 Assembler 被翻译成机器语言
