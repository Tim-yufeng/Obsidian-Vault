本章节大部分的笔记见课件，并且主要是对 Processor 结构图的理解，需要注意的点：
- ALU control 的输出并非谁与谁信号的组合，他是根据运算类型，给 add, subs, and, or  四种运算各分配了一个 4-bit数，此外，它接受来自主控制器 Control unit 的 2-bit 输入 ALUOp，但是这个输入仅仅是其参考之一，可以帮助其锁定 lw, sw, beq 三种运算，剩下的区分还需要借助完整的 Instruction

为评估CPU的性能，我们引入 CPU time, 即 CPU 完成一个任务所用的总时间，这里面又包含了 user CPU time 和 system CPU time

公式很简单，总时间就是总的 cycle 数，乘以每个cycle的用时：
![[Pasted image 20260604201524.png]]

而总的cycle 数，又可以分为：总的指令数（IC），乘以单个指令所用的cycle数（CPI），对于理想情况的 single-cycle-processor，CPI = 1

$$
\text{CPU time} = \text{IC} \times \text{CPI} \times \text{T}_{\text{C}}
$$
