`.s` 是汇编语言的一种扩展名，高级代码语言通过 Compiler 转化为汇编语言，然后再通过 Assembler 转变成计算机可以直接执行的机器语言，扩展名就是我们熟悉的 `.o`

### 汇编语言的前置知识

汇编语言（Assembly language）相比高级语言，应该说是优点不多，缺点一堆：
- 优点：是最贴近机器语言的语言，基本可以做到和机器语言行行对应，因此可以消除 Compiler引入的不确定性，可以直接决定代码的速度性能，（包括消除可能的编译器自动优化 which we don't want to)
- 缺点：难用，难 debug，而且几乎不能在其他机器上复用，因为汇编语言有很多，哪怕同一种汇编语言，在不同的CPU上也完全不能兼容

**ISA(Instruction Set Architecture)**：汇编语言中，能被计算机直接理解、使用的全部指令
本课程我们采用的是 RISC-V，32-bit

### 汇编语言的学习

#### 算术运算：

遵循三个运算数，第一个是目标地点（答案给谁），后两个是参与二元运算的数: 
```
add a, b, c    # a gets b + c
sub a, b, c    # a gets b - c
```

操作数（Operand）分为三类：
- Register operands
- Memory operands
- Immediate operands (constant)

主要用于存储更“大型”的数据，比如数组、结构体之类的
和寄存器堆中随用随得的数据不同，内存中和的数据需要先加载到寄存器堆，完成运算之后再存回去：

内存中的数据，遵循：每 byte，即 8 bits，都必须有一个独立的地址，那么我们知道我们研究的32-bit计算机，它的 data bus, register file 统统都是 32 bit 的，于是把4个 byte 排在一行，这就是 32-bit 了，这就是一个 word.


![[Pasted image 20260514230609.png]]

**Big Endian & Little Endian** 
我们知道一个 32-bit 的数据，有 4 byte, 比如对于图中这个数 `0x1020A0B0`，可以分为 `10`, `20`, `A0`, `B0` 4 个 byte。`10` 是最高位（most-significant byte），`B0` 是最低位（least-significant byte）
如果该行的**首地址**由**最低位占**据，就是 little endian 的存储方式，最高位则是 big endian
![[Pasted image 20260519183921.png]]

如我们之前所说，数组这种大型数据是存储在内存中的，其存储形式如图，可以看到，地址连续，相邻数据的地址相差4（因为1个word 4 byte，分配一个地址)，于是我们有一个数组的 base address，就可以知道数组内的任意项的地址，遵循 base address + offset

![[Pasted image 20260519184611.png]]

由此引出命令 `lw`, 即 load word，用来从memory中加载数据到寄存器堆，比如要加载一个数组 A 的 `A[8]`元素，基本语法：
```
lw x9, 32(x22)  # load word
```
其中 x22 是数组A的 base address, 32 是 offset（是的已经帮你算好了 4x8)，这个指令会从寄存器中 `x22` 中找到数组A的base address, 加上 offset, 用计算得到的地址去内存中加载出 `A[8]` 的数据，然后存回 `x9`

![[Pasted image 20260519185545.png]]

类似的，命令 `sw` ，即 store word，将计算后的数据存储回内存中：
```
sw x9, 48(x22)     # store word
```
这条指令的含义是，首先 `48(x22)` 获取目标地址，然后 将寄存器堆 `x9` 的数据存储进这个目标地址

#### Immediate operands (constant)

指的是 ==12-bit== 的，==带符号==的（二进制补位，记得吗），在指令中可以直接使用参与运算，有意思的是，有 Immediate operand 参与的指令都会在末尾加一个 'i'，例如：
```
addi x22, x22, 4
```
这其实就是一个新的指令了，注意没有 subi，因为完全可以用加一个负数来实现减法，指令集合是越精简越好的

**Constant Zero：** 在 RISC-V 架构中，**寄存器  x0** 是一个**只读的常量**，它硬连接在芯片内部，**永远存储数值 0**。
其用法包括：`add x9, x21, x0`, 来实现 x21 到 x9 的拷贝，或者 `add x9, x0, x0` 实现对 x9 的清零


| Instruction  | Category      | Example           | Meaning                              |
| :----------- | :------------ | :---------------- | :----------------------------------- |
| `add`        | Arithmetic    | `add x5, x6, x7`  | x5 = x6 + x7                         |
| `sub`        | Arithmetic    | `sub x5, x6, x7`  | x5 = x6 - x7                         |
| `addi`       | Arithmetic    | `addi x5, x6, 20` | x5 = x6 + 20                         |
| `lw`         | Data Transfer | `lw x5, 40(x6)`   | x5 = Memory`[x6 + 40]`               |
| `sw`         | Data Transfer | `sw x5, 40(x6)`   | Memory`[x6 + 40]` = x5               |
| `lui`        | Data Transfer | `lui x5, 0x12345` | x5 = 0x12345000 (load upper 20 bits) |
| `and`        | Logical       | `and x5, x6, x7`  | x5 = x6 & x7                         |
| `or`         | Logical       | `or x5, x6, x7`   | x5 = x6 \| x7                        |
| `xor`        | Logical       | `xor x5, x6, x7`  | x5 = x6 ^ x7                         |
| `slli`/`sll` | Shift         | `slli x5, x6, 3`  | x5 = x6 << 3                         |
| `srli`/`srl` | Shift         | `srli x5, x6, 3`  | x5 = x6 >> 3 (logical)               |
| `srai`       | Shift         | `srai x5, x6, 3`  | x5 = x6 >> 3 (arithmetic)            |
<span class="green"> 关于那三个 Shift 指令：</span>
- **右移** 有 `srai` 和 `srli` 的区别，是因为**右移涉及符号位的处理**。
    
    - 对**有符号数**（比如 -1，二进制全 1）右移，高位需要补 1 才能保持数值为负。这叫 **Arithmetic Shift Right（算术右移）**。
        
    - 对**无符号数**（比如 255，二进制全 1）右移，高位必须补 0，否则数值就变大了。这叫 **Logical Shift Right（逻辑右移）**。
        
- **左移** 的规则很统一：
    
    - 无论是有符号数还是无符号数，**左移都是低位补 0**。

关于 `lui` ，即 load upper immediate, 这个指令和前面那些带 i 的constant 指令有个区别，就是前面的针对 immediate operand，which 我们知道是 12-bit 的，但是这个 `lui` 处理的 constant是 20-bit 的，而且是从最高位往下的 20-bit，如图

![[Pasted image 20260520105942.png]]
这个指令的存在和前面那些只能处理前12-bit常数的指令构成了很好的互补，如果我们要将一个 32-bit 的常数加载进寄存器中，只需要先用 `lui` 加载前20位，然后 addi 把后12位加上就行了

其他条件语句包括：
```
blt rs1, rs2, L1   # rs1 < rs2

```

**循环语句:** 汇编语言中没有专门的循环命令如 while 什么的，循环是通过条件语句的跳转效果人为实现的，整个循环块本质上就是一个由许多小指令组成的大指令，其中需要包含维系循环的指令——一条跳转向循环开头的条件语句，和退出循环的指令——一条跳转向循环外的条件语句。
