# Configuration Space

这一节要回答的是 "Where is my robot?"——问题听起来幼稚，但它的答案决定了后面所有运动学、规划与控制内容要怎么写。

## 从"在哪"到坐标

课件用同一个问题串起五种机器人，每种给出的答案都是一组不同的坐标：

1. 轨道上的小车：一个角度 $\theta$；
2. 室内移动机器人：$(x,y,\theta)$；
3. 四旋翼：$(x,y,z)$ 再加三个转动，共 6 个；
4. 机械臂：$\theta_1,\dots,\theta_n$，每个关节一个角；
5. 蛇形机器人：底盘位姿 $(x,y,\theta)$ 再加 $n$ 个关节角。

五种系统、五份不同的坐标清单，说明真正要找的不是一张坐标表，而是一个能装下系统全部状态的对象。轨道那张 slide 里其实已经埋了伏笔：轨道闭合时 $\theta\in[0,2\pi)$，且 $\theta=0$ 与 $\theta=2\pi$ 是同一个状态；轨道不闭合时它只是一个区间。两者都只用一个实数坐标，却不是同一个空间——这个区别正是 C-space 的 **topology** 要处理的事。

## 基本概念

Rigid body 是任意两点间距离恒定的点集，slide 特意在括号里补了 "And no mirroring..."：允许刚体运动，不允许把物体镜像翻转。Robot 目前在课上先定义为一组 rigid body，也就是一组 links。Configuration 则是把机器人上所有点的位置都指定清楚。

<span class="red"> Degrees of Freedom (DoF)：表示 configuration 所需要的最少实数坐标个数。 </span>

"最少"不是修饰词，而是定义的一部分，它做两件事。第一，它让 DoF 成为 configuration 集合本身的性质，而不是某张坐标表的性质：三维刚体的姿态用 $3\times3$ 的 rotation matrix（9 个数）、单位四元数（4 个数）、Euler angles（3 个数）都能表示，但姿态空间的维数就是 3，所以 DoF 是 3。第二，它立刻指出后面所有麻烦的来源——手上的坐标数往往多于 DoF，多出来的部分要么彼此受约束，要么在某些位置上失效。教材因此明确选择了一套不最小、但处处不坏的表示：姿态一律用 rotation matrix（9 个数加正交约束），而不是 Euler angles。多坐标加约束的 implicit 表示不会出现坐标跳变或变化率无界；而恰好用满最少坐标数的 explicit 表示，只要 C-space 不是平坦的 $\mathbb{R}^n$，就一定会在某些点上出问题——下一节球面摆的两极就是最直观的例子。

各例的 DoF 可以直接数出来：平面刚体是位置 2 个加姿态 1 个，共 3 个；空间刚体是位置 3 个加姿态 3 个，共 6 个（四旋翼那张 slide 画的三条带箭头圆弧，就是这三个独立转动方向）；移动机器人是 $(x,y,\theta)$；开链机械臂的 DoF 等于关节数。

这些数字不是约定，而是数出来的。取空间刚体上三个不共线的点：第一个点可以任意放置，贡献 3 个自由数；第二个点虽然也有 3 个坐标，但必须落在以第一个点为球心的球面上，于是只剩 2 个自由度；第三个点再被一个球面约束钉住，只剩 1 个；此后所有点到这三点的距离都已给定，不再贡献自由度。$3+2+1=6$。平面情形用同一个数法：第一个点 2 个自由数，第二个点 1 个，第三个点 0 个，$2+1=3$。

一般地，自由度等于各点的自由数之和减去独立约束数，写成方程就是：若 configuration 由 $n$ 个变量描述、并满足 $k$ 个独立约束，则 $dof=n-k$。对由连杆和关节组成的机器人，教材把它写成 Grübler 公式

$$
dof = m(N-1)-\sum_{i=1}^{J}c_i
$$

其中 $N$ 是连杆数（按惯例把 ground 也算作一个 link），$J$ 是关节数，$m$ 是单个刚体的自由度（平面为 3，空间为 6），$c_i$ 是第 $i$ 个关节施加的约束数。它有一个容易忘掉的前提：这些约束必须彼此独立。闭链机构里这个前提经常不成立，教材就给出了一个被 Grübler 公式算成 0 自由度、实际却仍有 1 个自由度的机构作为反例。

## Configuration Space

<span class="red"> Configuration Space (C-space)：所有可能 configuration 的集合，其维数等于 DoF。 </span>

Slide 列的第三点是整节课的纲：C-space 有 **topology** 与 **representation** 两层——先有集合，再有形状，最后才是坐标系。

### 同一个平面，不同的参数化

![[Pasted image 20260915182350.png]]

Point on a plane 的 C-space 拓扑是 $\mathbb{E}^2$，最自然的表示是两个实数 $\mathbb{R}^2$。Slide 在这里追问了一句 "Any other representation/parametrization?"，旁边的图给的是极坐标：同一个平面改用 $(r,\varphi)$ 描述，拓扑没有任何变化，但表示本身多了一个坏点——原点处 $\varphi$ 没有定义。表示是人为选择，可以选择得好，也可以选择得让某些位置没法写。

### 两个同为 2 维、形状却不同的 C-space

![[Pasted image 20260915182351.png]]

球面摆（spherical pendulum）的 configuration 由摆杆的单位方向向量完全决定，而单位方向向量的集合是球面 $S^2$。课件给它的表示是纬度与经度，写成矩形 $[-180^\circ,180^\circ)\times[-90^\circ,90^\circ]$（经度 × 纬度）。这张经纬图不是球面的忠实复制：图的上边缘整条线段都对应北极，下边缘整条线段都对应南极，而球面上北极只是一个点。教材把这类点称为表示的 singularity，并特别强调它与球面本身的拓扑无关——球面到处长得一样，出问题的只是我们的表示。也就是说，$S^2$ 上不存在一张既覆盖全空间、又处处一一对应的坐标图。

2R 机械臂的两个转角各自取值在一个圆上，所以它的 C-space 是 $T^2=S^1\times S^1$，表示成 $[0,2\pi)\times[0,2\pi)$ 的正方形，但四条边要成对粘合：左粘右、上粘下。那个正方形不是 C-space 本身，只是它的一张图。

<span class="green"> 这和线性代数里换基底是同一件事的两面：换一组基底不改变向量本身，只是换了读它的方式；换一套参数化也不改变 C-space，只是换了写它的方式。代价则落在写法上——机器人在环面上平滑地绕过一圈时，它的坐标表示会突然跳一次。 </span>

这个代价不是审美问题。在实数轴上"直线插值"是天然操作，在圆上却不是：两个 configuration 之间按坐标直接线性插值，只要有一个分量跨过回绕点，机器人就会绕远路，甚至朝反方向转一大圈。

## 两个待回答的问题

### Is $S^2=S^1\times S^1$?

不等于。两者都是 2 维紧流形，所以维度完全无法区分它们，必须动用到拓扑。一种说法从闭路出发：在环面上"固定 $\theta_2$、让 $\theta_1$ 从 $0$ 转到 $2\pi$"这条闭路，无论怎样连续变形都缩不成一个点，因为它绕过了粘合的边；而球面上任何一条闭路都能连续收缩成一个点。另一种说法直接看上面那张图：环面的正方形表示里，边只是被粘合，没有任何退化；球面的经纬图里，上下两条边整条塌缩成一个点——塌缩本身就说明这张图不可能是同胚。

这就是 "C-spaces of the same dimension can have different topologies" 的具体含义，也说明"关节角回绕"这类现象不能当成数值细节：它是 C-space 的形状决定的。

### 两个手腕的 C-space 相同吗？

![[Pasted image 20260915182352.png]]

Slide 只提出问题，没有给答案，但要回答它，得先承认问题里藏了一个前提："手腕的 C-space"指的到底是什么。

如果指两个关节角 $(\theta_A,\theta_B)$ 构成的空间，那么无论两轴平行、相交还是异面，它都是 $T^2$——轴线几何只改变正运动学这个映射，不改变关节空间本身，两个手腕没有区别。真正的差别只会出现在"手腕能把末端指向哪些方向"上。两轴平行时，两次转动绕同一方向且次序可以交换，指向只由 $\theta_A+\theta_B$ 决定，方向集合退化成一条圆 $S^1$，两个坐标里有一个成了冗余，这正好用上了 DoF 定义里的"最少"。两轴垂直、相交、且末端指向垂直于第二轴时（pan-tilt 构型），$\theta_B=\pm 90^\circ$ 两条整圆周被映射压成两个极点，像集覆盖整个 $S^2$，与球面摆的经纬图完全同构——这两个极点就是 gimbal lock，也正是上面那个必须切开的 singularity。若两轴以斜角相交、或末端指向不垂直于第二轴，能到达的只是球面上的一条带，而不是整张 $S^2$。

按课件把同类工业臂放进球面摆那一行的做法，它引导的显然是"指向"这一读法，此时两个手腕不同构；而二维投影里两条线"看起来相交"与三维中真正相交无法区分，所以这个判断只能回到实物或三维模型去确认。课件本身没有给出结论。

顺带一个容易忽略的点：C-space 相同或不同，并不直接决定末端能到达的位置集合（workspace）。同样的 C-space 配上不同长度的连杆会得到不同的 workspace，而不同的 C-space 也可能覆盖同一片 workspace——workspace 是 C-space 经正运动学投影后的像，两者的信息并不互相决定。所以"两个手腕是否同构"值得问，但这个答案不足以直接回答"它们能不能做同样的事"。

## C-Space 障碍

![[Pasted image 20260915182353.png]]

左图是 workspace：一个 2R 机械臂、四个黑色方块障碍，以及 start 与 end 两个姿态。右图是同一个问题的 C-space：横纵轴换成 $\theta_1,\theta_2$，灰色阴影是 C-obstacle，也就是"在这个 configuration 下机器人会碰到障碍"的那些点组成的集合，虚线是 start 到 end 的一条路径。

关键动作是换变量：机器人在 workspace 里是一个有形状、会转动的物体，在 C-space 里它只是一个点。于是"机器人不与障碍相交"这个条件，从"两个几何体不相交"变成了"这个点不在某个区域里"。代价是 C-obstacle 的形状通常远比 workspace 里的障碍复杂——对比左图四个干净的方块和右图那些弯曲的阴影。另外，右图的 $\theta_1$ 方向同样存在回绕：真正的 C-space 是环面，从右边走出去会从左边回来。

拓扑在这里第一次真正起作用：C-space 里到底有没有路，取决于 free space 的连通性；路径长什么样是第二位的问题。

障碍映射到 C-space 是 motion planning 的第一步，教材在讲运动规划的部分才正式展开 C-space obstacles，这一节只需要知道它是什么、以及为什么要做这个变换。

## 分析一个机器人的 C-space

Slide 的学习目标要求 "be able to analyze the configuration space of robots"，把上面各例的做法收束成一组可执行步骤：

1. 数出最小的独立坐标数，得到 DoF，也就得到 C-space 的维数；
2. 逐个判断每个坐标的定义域：平移对应实数轴 $\mathbb{R}$，转动对应圆 $S^1$；
3. 用乘积拼出拓扑，例如移动机器人的 $\mathbb{R}^2\times S^1$、2R 臂的 $T^2$、空间刚体的 $\mathbb{R}^3\times SO(3)$；
4. 选一张表示，并记下它的坏点：切开处导致的坐标跳变，以及纬度图两极那样的退化点；
5. 若环境里有障碍，再把它映射成 C-space 里的 C-obstacle，并在 free space 上判断连通性与路径。

第 3 步不能无条件当成"乘积"来写：球面摆的 $S^2$ 就不是任何两个 $S^1$ 或 $\mathbb{R}$ 的乘积，这正是上面那个问题要说明的事。
