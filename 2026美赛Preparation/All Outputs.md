## ① 三种运输情景（a 电梯 / b 火箭 / c 混合）

### 你必须输出什么（结果形态）

1. **总工期**：把 $10^8$ 吨运完需要多少年/多少天（分情景 a/b/c）。
2. **总成本**：总成本（以及分解：建造/运营/发射/维护/燃料或电力/地面保障等）。
3. **单位成本**：$/t 或 ¥/t（方便横向比较）。
4. **吞吐量与调度**：

   * 每年运输量曲线（是否恒定/是否受基地数量、火箭频次、电梯故障影响）。
   * 混合方案下“电梯占比 vs 火箭占比”的最优分配（时间/成本/环境权重变化下的解）。
5. **可行性判定**：例如“在 2050 后 X 年内是否能完成”。

### 推荐图像（越贴题越好）

* **堆叠柱状图**：三情景的成本构成（成本分解一眼看清）。
* **折线图**：累计已运输质量 $M(t)$（或剩余质量）随时间变化（三条曲线对比工期）。
* **甘特图/时间轴图**：显示“电梯段 / 火箭段 / 等待/周转”在年度尺度的占比（尤其混合方案）。
* **Pareto 前沿图**（若做多目标）：横轴成本、纵轴时间（或环境），给出混合方案的 Pareto 曲线，并标注你选的折中点。

### 要不要敏感性/鲁棒/消融？

* **敏感性：必须有**（至少对“年运力”“单次载荷”“单位成本”“发射频率”“能耗价格”“折旧周期”等关键参数）。
* **鲁棒性：建议有**（对不确定性扰动下，最优分配比例是否稳定）。
* **消融实验：不叫消融也行，但建议做“模块开关对比”**：

  * 只看时间（$w_T=1$）
  * 只看成本（$w_C=1$）
  * 加入环境项（$w_E>0$）
    看结论是否“翻盘”。

### 补充实验怎么画

* **龙卷风图（Tornado）**：每个参数上下浮动 ±x% 对“总成本/总工期”的影响条形排序。
* **权重热力图**：$(w_C,w_T,w_E)$ 网格下，“最优方案类别/电梯占比”的颜色分区图（非常直观）。

## ② 非理想工况（摆动/故障/失败）

### 你必须输出什么

1. **非理想条件下的期望成本与期望工期**：$E[\text{Cost}], E[\text{Time}]$。
2. **风险指标**：

   * 完成时间的分位数：$P_{90}(\text{Time})$、$P_{95}$（“最坏 10% 情况要多久”）。
   * 超期概率：$\Pr(\text{Time}>\text{deadline})$（如果你们设置“希望 30 年内完成”这种政策目标）。
3. **策略变化**：非理想情况下，最优“电梯/火箭分配”是否明显偏向某一方。

### 推荐图像

* **直方图 / 核密度图**：Monte Carlo 下总工期、总成本的分布。
* **箱线图/小提琴图**：三情景在随机扰动下的分布对比（鲁棒性一眼看出）。
* **可靠性曲线**：横轴时间，纵轴“已完成概率/完成比例”的曲线。
* **情景树**（可选）：少量离散故障情景（轻微/中等/严重）对应的结果对比。

### 要不要敏感性/鲁棒/消融？

* **鲁棒性：这里是主菜，必须有**（因为题目点名“不完美运行”）。
* **敏感性：必须有**（对故障率、维修时间、失败概率、天气停运比例等做局部敏感性）。
* **消融：可做“去掉某类风险项”的对比**：

  * 只考虑火箭失败
  * 只考虑电梯停运
  * 两者都考虑
    看哪个风险项主导结论。

### 补充实验怎么画

* **累计概率曲线（CDF）**：工期的 CDF，能清楚读出 $P_{90}$。
* **散点云图**：每次模拟的（成本，工期）点云，叠加“理想点”，展示风险下的扩散。

## ③ 水资源需求（建成后一年）

### 你必须输出什么

1. **一年需水总量**：人均 × 人口 × (1 − 回收率) + 工农业/系统冗余（你们假设的部分要写清）。
2. **为满足一年供水所需的额外运输量、成本、时间**（基于你前面运输模型直接算）。
3. **对运输系统的影响**：水运输是否挤占建材运力？是否需要“提前库存”策略？

### 推荐图像

* **桑基图/流量图**：水的来源→回收→损失→补给（闭环系统视觉冲击强）。
* **柱状图**：不同回收率（90/95/98%）下的年补给水量对比。
* **叠加折线**：把“建材累计运输 $M(t)$”和“水库存 $W(t)$”放在同一时间轴（双轴或归一化）。

### 要不要敏感性/鲁棒/消融？

* **敏感性：必须有**（回收率、生活用水定额、人口波动、农业比例是最大不确定源）。
* **鲁棒性：建议有**（如果你们用 Monte Carlo 给“缺水概率”）。
* **消融：建议做“只生活用水 vs +农业/工业”的增量贡献**（非常像消融，且符合叙事）。

### 补充实验怎么画

* **缺水风险曲线**：横轴时间，纵轴“库存低于阈值的概率”。
* **参数扫描曲线**：回收率 $r$ 从 0.8→0.99，输出年补给量 $W(r)$。

## ④ 地球环境影响（并优化最小化）

### 你必须输出什么

1. **环境影响指标**（至少给一个可计算指标）：

   * 如 CO₂ 当量、黑碳、NOx 或“污染指数”（你们可以定义加权指标，但必须解释权重来源/合理性）。
2. **三情景环境影响对比**：总排放、单位吨排放。
3. **最小化环境影响的最优策略**：

   * 约束型：排放 ≤ 阈值，最小化成本/时间
   * 或多目标：最小化（成本、时间、排放）的 Pareto 集

### 推荐图像

* **成本–排放–时间的 2D/3D 图**：

  * 2D：排放 vs 成本（或排放 vs 时间）的 Pareto 前沿
  * 3D：三个目标散点 + 前沿（可选，容易花但很有说服力）
* **堆叠柱状图**：不同阶段（地面/发射/轨道转移等）对排放贡献占比。
* **权衡曲线**：排放阈值从严到松，最优成本/工期如何变化（政策含义很强）。

### 要不要敏感性/鲁棒/消融？

* **敏感性：必须有**（因为环境系数通常争议大、数据不确定）。
* **鲁棒性：建议有**（如果你给了“排放因子范围”，用区间或分布）。
* **消融：强烈建议**：

  * 不考虑环境时的最优解
  * 加入环境后最优解
    用同一张图展示“政策介入导致的策略迁移”。

### 补充实验怎么画

* **阈值扫描图**：$E_{\max}$ 从小到大 → 最优（成本、工期）曲线。
* **不确定性带状图**：排放因子取区间时，结果用阴影带表示置信范围。

## ⑤ 一页建议信（Recommendation Letter）

### 你必须输出什么

* **结论不是“选哪个”一句话**，而是：

  1. 推荐方案（a/b/c）+ 推荐的配比（若混合）
  2. 理由：成本、工期、环境、风险四维度的证据
  3. 风险与对策：关键风险、预案（备份运力、库存策略、冗余港口等）
  4. 可执行路线图：比如 2050–2060 建材、2060–2065 关键系统、2065 后运营补给

### 推荐图像（信里最多 1–2 张）

* **一张雷达图**：成本/工期/环境/风险四维评分（能一眼说服）。
* 或 **一张 2D Pareto 图**：标出你选的折中点 + 备选点。

# 统一要求：自检、异常处理、你们要不要写？

## 自检与异常处理（建议写成一个小节，强烈加分）

至少包括：

1. **量纲检查**：所有公式的单位一致（$t$、$kg$、$N$、$kWh$、$J$）。
2. **边界测试**：

   * 失败率=0 应回到理想工况
   * 运力→∞ 工期→0（但成本不一定）
   * 电梯运力为 0 时混合方案退化为纯火箭
3. **异常值处理**（尤其 Monte Carlo）：

   * 若出现负成本/负时间，直接判为模拟失败并重采样或截断
   * 极端故障导致“不可完成”，要输出“不可行概率”而不是硬算一个数

## 结果一致性检查（很加分）

* **两种方法算同一个量**做交叉验证：

  * 由年运力估算工期 vs 由调度仿真累计到 $10^8$ 吨的工期
    应在允许误差内一致。

# “敏感性 vs 鲁棒性 vs 消融”怎么在文中说得自然

* **敏感性分析**：参数不确定 → 结论对哪些参数最敏感（用龙卷风图/局部导数/弹性）。
* **鲁棒性分析**：随机故障/扰动 → 结论在概率意义下是否稳（用分布、分位数、超标概率）。
* **消融实验**：把模型机制逐个关闭 → 证明“你加入的机制是必要的”（非常适合你们这种“成本-时间-环境-风险”综合模型）。
