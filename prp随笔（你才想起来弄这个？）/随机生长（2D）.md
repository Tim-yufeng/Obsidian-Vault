既然 `.inp` 文件已经成功生成，接下来的核心是将这个有限元模型作为**统计体积单元 (SVE)**，通过施加**周期性边界条件 (PBC)** 来计算等效杨氏模量 $E_{avg}$ 和泊松比 $\nu_{avg}$。

手动在 Abaqus/CAE 中为 18000 个模型施加 PBC 是不现实的。必须通过 Abaqus Python API 实现全流程自动化。

然后我要尝试复现论文中的其他几张图，关于 Fig3, A, 这张图其实是解释为什么后面采用 20x20 作为 SVE（统计体积单元）
简单解释一下这玩意，对于规则的材料结构，比如像晶胞那种，我们只需要选一个很小的重复结构进行研究，这个结构就能代表整体的性能
但是对于不规则的结构，我们需要额外确定，选取多大的一块结构，它的性能具有代表整个接近无穷大的材料结构性能的能力
于是乎，论文探讨了 5x5, 10x10, 20x20 的情形下，分别作均质化，杨氏模量和泊松比的平均值和误差棒，最右边的REF是一个标杆，是采用40x40，并且纯仿真得到的性能，发现 20x20 均质化得到的结果已经非常接近 40x40 的结果，说明了 20x20 已经可以作为SVE进行后续研究了
![[Pasted image 20260419144224.png]]
