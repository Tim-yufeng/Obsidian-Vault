### 0. 准备工作：确定材料参数

在开始建模前，请记录你之前对 `MatTiles_186_0` 提取的等效参数（参考你的 CSV 结果）：

- **有效杨氏模量 ($E_{eff}$)**：例如 $0.038902 \times 52.53 \approx 2.044$ MPa 。
    
- **有效泊松比 ($\nu_{avg}$)**：直接取自CSV文件，为 $0.071251$ 。
    

---

### 第一阶段：几何建模 (Part & Sketch)

1. **创建零件**：点击 `Module: Part` -> `Create Part`。
    
    - Name: `Continuum_Hole`
        
    - Modeling Space: `2D Planar`
        
    - Type: `Deformable`
        
    - Base Feature: `Shell`
        
2. **绘制草图**：
    
    - 使用 `Create Lines: Rectangle` 画一个以 $(0,0)$ 为中心或左下角的 $100 \times 100$ 正方形。
        
    - 使用 `Create Circle` 在中心点 $(50,50)$ 绘制一个半径为 $15$ 的圆 。
        
    - 点击 `Done` 完成。此时你得到一个中心带孔的 2D 平板。
        
(建议直接输入坐标！比徒手拖方便的多！一气呵成，最终会自动把中间的圆盘裁去的)

---

### 第二阶段：材料与截面 (Property)

1. **创建材料**：`Module: Property` -> `Material` -> `Create`。
    
    - Name: `Homogenized_Mat`
        
    - `Mechanical` -> `Elasticity` -> `Elastic`：
        
        - Young's Modulus: 输入计算出的 **$E_{eff}$**。
            
        - Poisson's Ratio: 输入提取出的 **$\nu_{avg}$**。
            
2. **创建截面**：`Section` -> `Create`。
    
    - Category: `Solid`, Type: `Homogeneous`。
        
    - Thickness: 输入 `1.0`（必须与不规则模型的一致） 。
        
3. **指派截面**：点击 `Assign Section`，选中整个平板，选择刚创建的 `Section`。
    

---

### 第三阶段：装配与分析步 (Assembly & Step)

1. **实例零件**：`Module: Assembly` -> `Instance Part` -> 选中 `Continuum_Hole` -> `OK`。
    
2. **创建分析步**：`Module: Step` -> `Create Step`。
    
    - Procedure type: `General` -> `Static, General`。
        
    - 保持默认参数，点击 `OK`。
        

---

### 第四阶段：边界条件与载荷 (Load/BC)

为了保证对比的严谨性，边界条件必须与你的 `homogenize.py` 脚本逻辑完全对齐：

1. **固定左边**：`BC` -> `Create` -> `Displacement/Rotation`。
    
    - Step: `Initial`
        
    - 选中左侧边缘线，勾选 `U1 = 0`。
        
2. **防止旋转/刚体位移**：
    
    - 选中底边边缘线，勾选 `U2 = 0`。此操作模拟了脚本中的 `Fix_Bottom` 逻辑，确保模型只沿 X 方向伸缩 。
        
3. **右侧拉伸**：`BC` -> `Create` -> `Displacement/Rotation`。
    
    - Step: `Step-1` (或 `Load`)
        
    - 选中右侧边缘线，勾选 `U1 = 1.0` (代表 1% 宏观应变)。
        

---

### 第五阶段：网格划分 (Mesh)

1. **单元类型**：`Module: Mesh` -> `Mesh` -> `Element Type`。
    
    - 选中整个平板，选择 `Plane Stress`，族选 `CPS4R`（减缩积分，必须与不规则模型一致，防止自锁） 。
        
2. **布子**：`Seed` -> `Part`。
    
    - Size: 设定为 `0.25`（这会产生 $400 \times 400$ 级别的精细网格，与 20x20 瓦片的像素分辨率对齐）。
        
3. **划分**：点击 `Mesh Part`。
    

---

### 第六阶段：提交任务与结果分析 (Job & Visualization)

1. **运行任务**：`Module: Job` -> `Create` -> `Submit`。
	
2. **获取结果图：** 注意通过右上角的箭头把Step time由0改到1！不然你的板子就是一片蓝零形变哈哈哈哈哈
    
3. **结果对比逻辑**：
    
    - **均质板 (A图)**：你会观察到圆孔左右两侧（垂直于拉伸方向）出现深红色的亮斑。最大 Mises 应力与无孔状态的比值理论上接近 **3.0** 。
        
    - **不规则结构 (B图)**：打开你之前生成的 `MatTiles_186_0.odb`。
        
    - **对比关键点**：由于不规则网络中梁的非均匀排布，应力通过冗余路径进行了重定向。你会发现不规则结构开孔前后的 **$\max(\sigma_{V})$** 几乎没有剧烈波动（比值接近 1.0），这证明了该结构对缺陷的极度不敏感性 。
        

**操作技巧**：将两个窗口平铺（`Canvas` -> `Viewport Layer Editor`），统一两者的图例限值（Legend Limits），即可直接生成用于汇报的对比图 。
