作者开源了二维的随机生长代码，二维构成块，开源代码是用 C#写的 [[随机生长的开源代码]]，需要用 dotnet 运行：
```bash
dotnet restore
dotnet run
```
运行结果包括一个 Dense 4 weights.txt，描述组号和目标频率的对应关系
一个Dense4文件夹，内部含18000个txt文件，包含 building blocks 的排列方式数据，为了把这些数据变成实实在在的模型，我整了一个C++脚本：`TxtToInp.cpp` ，自动把txt的数据映射到 inp 模型，能直接导入 Abaqus的那种

本来有个Makefile来自动编译他的（还留在仓库里面），但是后来改着改着就不适用了，于是用 `g++ -std=c++17 TxtToInp.cpp -o TxtToInp` 来手动编译，单个 txt 文件的转化用 `./TxtToInp "Dense4/encode MatTiles_137 4.txt"` (举个例子)
后来觉得运行太麻烦，因为我在调试阶段每次都让他单独转化出6个 inp（1个太少，18000个全部转化会直接挤爆我的D盘空间）
所以把编译和运行都包含在了一个 `generate_samples.sh` 文件内，直接运行即可同时完成编译和6个 inp 的转化：
```bash
./generate_samples.sh
```

[[初生Inp的Abaqus形态解读]]

既然 `.inp` 文件已经成功生成，接下来的核心是将这个有限元模型作为**统计体积单元 (SVE)**，通过施加**周期性边界条件 (PBC)** 来计算等效杨氏模量 $E_{avg}$ 和泊松比 $\nu_{avg}$。

手动在 Abaqus/CAE 中为 18000 个模型施加 PBC 是不现实的。必须通过 Abaqus Python API 实现全流程自动化。

于是，有了现在这一版被修改了N多遍的 `homogenize.py`，作用是从前一个脚本，就那个`TxtToInp.cpp`，输出 inp 的文件夹`InpOutputs`，中源源不断的导入 inp 到 Abaqus，驱动 Abaqus 完成分析工作，最后把等效的杨氏模量和泊松比数据输出到一个 CSV 文件 `Homogenization_Results` , 包含在文件夹 `Abaqus_Results`内

PyCharm打开一片红是正常的，因为他是Abaqus驱动，很多包是Abaqus自带，不在你的 python 环境里，要运行，需要在仓库打开终端，Windows环境下（不要转到 wsl !）运行：
```shell
& "D:\my_Software\CAE\SIMULIA\Commands\abq2025.bat" cae noGUI=homogenize.py
```

导出的结果包括 odb 文件，可以用 Abaqus 直接打开，展示效果图
- 打开 Abaqus CAE 界面，点击 `File` -> `Open`，选择 `MatTiles_186_0.odb`。
    
- 点击 `Plot Contours on Deformed Shape`（彩色云图按钮）。
	
- Section（好像是？）里面 VOID_SET 右键选择 remove，不显示它，并且在上方 **Options** -> **Common** 找到 No edges, 黑色的边缘会干扰颜色观察
	
- 然后就得到了一大堆 odb 的图像啦 [[ODB图像展示]]
