### 二、核心脚本详解

#### 1. 瓦片定义：`data.xml`

**路径**: `Virtual_Growth_Program_2D/samples3d/OrthoFig6B/data.xml`

**内容格式**（已从探索结果了解）：
```xml
<tiles>
  <tile name="line_x" .../>    <!-- 定义所有可用瓦片 -->
  <tile name="corner_xy_pp" .../>
  <tile name="cross_xyz" .../>
  <tile name="void" .../>
  ...
</tiles>
<subsets>
  <subset name="OrthoFig6BSet2">   <!-- 子集：定义构建块集合 -->
    <tile name="line_x"/>
    <tile name="line_y"/>
    <tile name="line_z"/>
    <tile name="corner_xy_pp"/>
    <tile name="corner_xy_pn"/>
    ...
  </subset>
</subsets>
```

**用途**: 定义瓦片名称列表和子集，供 catalog 脚本和 WFC 生成使用。包含约 21 个 OrthoFig6B 3D 瓦片。

---

#### 2. TXT 生成：`generate_wfc_3d_programmability_txts.py`

**路径**: `Virtual_Growth_Program_TPMS/generate_wfc_3d_programmability_txts.py`

**输入参数**:
- `--groups N`：生成几组概率组合（对应 g000, g001, ... 目录）
- `--per-group M`：每组几份随机种子
- `--width/height/depth`：3D 网格尺寸
- `--subset`：使用 data.xml 中的哪个子集
- `--cross-weight` / `--corner-weight` 等：概率权重参数
- `--WFC-binary`：C# 可执行文件路径

**内部流程**:
1. 读取 `data.xml` 获取瓦片列表
2. 用概率权重构建瓦片出现概率分布
3. 每个种子（--per-group）：调用 C# 可执行文件运行 WFC 算法
4. C# 输出 `encode3d_*.txt` 到 `g###/` 目录

**输出**:
```
WFC_3D_OUTPUT_DIR/
├── g000/
│   ├── encode3d_OrthoFig6B_s000.txt
│   ├── encode3d_OrthoFig6B_s001.txt
│   └── ... (共 --per-group 份)
├── g001/...
├── group_weights.csv
└── ...
```

**TXT 文件格式** (3D):
```
# z=0
cross_xyz, 0, line_x, 0, corner_xy_pp, 0
line_y, 0, void, 0, corner_xy_np, 1
...
# z=1
...
```

每行是 WFC 的一行网格瓦片，逗号分隔，每个瓦片格式为 `名称, 旋转量`。3D 用 `# z=数字` 头分层。

**2D 无专门 generate 脚本**——但 2D WFC 的生成在 C# 项目的 `2d-batch` 模式中。可以直接检查是否有 `encode2d*.txt`。

---

#### 3. 核心管线：`tpms_pipeline.py`

**路径**: `Virtual_Growth_Program_TPMS/tpms_pipeline.py`

**输入参数**:

| 参数                          | 2D 默认     | 3D 默认     | 说明                      |
| --------------------------- | --------- | --------- | ----------------------- |
| `--mode`                    | **必填**    | **必填**    | `2d` 或 `3d`             |
| `--input-txt`               | **必填**    | **必填**    | WFC encode*.txt 路径      |
| `--output-dir`              | `outputs` | `outputs` | 输出目录                    |
| `--resolution`              | `12`      | `12`      | 每瓦片像素数(2D)/体素数(3D)      |
| `--radius`                  | `0.18`    | `0.19`    | 杆半径                     |
| `--tpms-k`                  | `0.06`    | `0.06`    | Schwarz 调制强度            |
| `--tpms-period-scale`       | `1.0`     | `1.0`     | Schwarz 周期缩放            |
| `--grid-shape`              | 自动推断      | 自动推断      | 强制指定网格形状 NxN 或 ZxYxX    |
| `--component-filter`        | `largest` | `largest` | 是否只保留最大连通分量             |
| `--length`                  | `100.0`   | `100.0`   | 模型物理尺寸                  |
| `--2d-fe`                   | `cdt`     | N/A       | 2D: cdt(平滑) 或 voxel(阶梯) |
| `--contour-simplify-tol-px` | `0.15`    | N/A       | 2D: 轮廓简化容差              |
| `--cdt-min-angle`           | `28.0`    | N/A       | 2D: 三角剖分最小角             |
| `--export-voxel-inp`        | 否         | 否         | 是否额外输出体素 INP            |
| `--minimal-3d-export`       | N/A       | 否         | 3D: 仅输出 .npy+metrics    |
| `--shell-thickness`         | N/A       | 默认计算      | 3D: 壳厚度                 |
| `--junction-radius`         | N/A       | 默认计算      | 3D: 节点半径                |
| `--connector-radius`        | N/A       | 默认计算      | 3D: 连接器半径               |
| `--shell-section-thickness` | N/A       | `0.8`     | 3D: Abaqus 壳截面厚         |
| `--log-tile-interval`       | `0`       | `0`       | 进度日志间隔                  |


**内部流程** (2D):
```
parse_wfc_tokens(txt) → GridData
build_implicit_2d(data) → field, mask, info
  ├── tile_connectors_2d → 解析每个瓦片的端口方向
  ├── add_oriented_cell → 创建方形 Schwarz 胞元
  ├── Gaussian blur → field 平滑
  ├── solve_threshold → 自动求等值面阈值 C
  └── component_filter → 保留最大连通分量
export_cdt_from_field(field, mask, C) → CPS3 INP
  └── find_contours(field, C) → 平滑等值线 → Triangle CDT
write_smooth_2d_stl → tpms_2d.stl
```

**内部流程** (3D):
```
parse_wfc_tokens(txt) → GridData
build_implicit_3d_schwarz_p(data) → field, mask, info
  ├── tile_connectors_3d → 解析 6 方向端口
  ├── add_tpms_half_cell → 创建 L∞ box 杆段+端盖
  ├── add_junction → 节点 L∞ box
  └── component_filter → 保留最大连通分量
write_smooth_isosurface_stl(field, 0.0) → tpms_3d.stl
  └── marching_cubes → 三角等值面
write_smooth_solid_inp_via_gmsh(stl) → tpms_3d_smooth_solid.inp
  └── Gmsh → 四面体实体网格
write_shell_inp_from_isosurface → tpms_3d_shell.inp
```

**输出文件**:
```
{output-dir}/
├── field_2d.npy / field_3d.npy         [隐函数场]
├── field_mask_2d.npy / field_mask_3d.npy [二值掩膜]
├── tpms_2d.inp / tpms_3d_smooth_solid.inp [主 INP]
├── tpms_2d.stl / tpms_3d.stl              [STL 曲面]
├── tpms_3d_voxel.stl (可选)              [体素 STL]
├── tpms_3d_shell.inp                      [壳 INP]
└── metrics.json                           [元数据]
```

#### 4. 2D CDT 网格：`tpms_2d_cdt_mesh.py`

**路径**: `Virtual_Growth_Program_TPMS/tpms_2d_cdt_mesh.py`

**用途**: 被 `tpms_pipeline.py` 内部调用，不独立运行。从 2D 场值提取平滑等值线，构建 PSLG，调用 Triangle 库生成约束 Delaunay 三角剖分，写入 CPS3 单元 INP。

**函数**: `export_cdt_from_field(field, mask, c_threshold, ...)` → `CPS3》` Abaqus INP

**依赖**: numpy, skimage.measure.find_contours, triangle 库

---

#### 5. 批量处理：`batch_tpms_inp.py`

**路径**: `Virtual_Growth_Program_TPMS/batch_tpms_inp.py`

**输入参数**:
- `--wfc-2d-batch`：2D WFC 输出目录（含 g###/ 子目录）
- `--wfc-3d-batch`：3D WFC 输出目录
- `--out-2d`/`--out-3d`：输出目录（默认 `batch_inp_2d/`、`batch_inp_3d/`）
- `--only-2d`/`--only-3d`：仅处理 2D 或 3D

**内部流程**:
1. 扫描 `--wfc-*-batch/g###/encode*.txt`
2. 对每个 txt：调用 `tpms_pipeline.py` 子进程
3. 移动 INP 到输出目录

**输出**:
```
batch_inp_2d/
└── g000/
    ├── g000_s001_tpms_2d.inp
    └── g000_s002_tpms_2d.inp
batch_inp_3d/
└── g000/
    ├── g000_s001_tpms_3d.inp      (其实是 tpms_3d_smooth_solid.inp)
    ├── g000_s001_metrics.json
    └── ...
```

---

#### 6. 单瓦片 INP 目录生成

**generate_ortho_tile_inp_catalog.py** (3D):
- 遍历 data.xml 中 `OrthoFig6BSet2` 子集的瓦片
- 每个瓦片写 `1x1x1` txt → 调用 `tpms_pipeline.py --mode 3d` → 复制 `tpms_3d_smooth_solid.inp`
- 输出: `OrthoFig6B_tile_inp_catalog/{tile_name}.inp`

**generate_ortho_tile_2d_inp_catalog.py** (2D):
- 遍历 data.xml 中 `OrthoFig6B` 子集的瓦片
- 每个瓦片写 `1x1` txt → 调用 `tpms_pipeline.py --mode 2d` → 复制 `tpms_2d.inp`
- 输出: `OrthoFig6B_tile_2d_inp_catalog/{tile_name}.inp`

### 四、完整工作流执行步骤

#### 步骤 0：前置安装
```bash
# Python 依赖
pip install numpy scipy scikit-image triangle gmsh

# .NET SDK (WFC C# 项目需要)
# 从 https://dotnet.microsoft.com/download 安装 .NET 8.0
```

#### 步骤 1：生成 WFC TXT 文件

**3D - 5 种概率组合 × 10 个随机模型**:
```bash
python3 generate_wfc_3d_programmability_txts.py \
    --groups 5 \
    --per-group 10 \
    --width 6 --height 6 --depth 6 \
    --WFC-binary ../Virtual_Growth_Program_2D/bin/Release/net8.0/VirtualGrowthProgram
```
输出到 `wfc_3d_dense_programmability/` 或 `WFC_3D_OUTPUT_DIR/g{000-004}/encode3d_*.txt`

**2D - 类似**:
需要检查是否存在 `generate_wfc_2d_programmability_txts.py`。如果不存在，2D WFC 的生成在 C# 项目的 `2d-batch` 模式下，用法：
```bash
cd ../Virtual_Growth_Program_2D
dotnet run -- 2d-batch --groups 5 --per-group 10 --width 12 --height 12
```

#### 步骤 2：TXT → INP 映射

**单个模型直接映射**:
```bash
# 2D
python3 tpms_pipeline.py --mode 2d --input-txt encode2d_xxx.txt \
    --output-dir out_2d --resolution 40 --radius 0.18 --tpms-k 0.06

# 3D  
python3 tpms_pipeline.py --mode 3d --input-txt encode3d_xxx.txt \
    --output-dir out_3d --resolution 18 --radius 0.24 --tpms-k -0.2
```

**批量映射（推荐）**:
```bash
# 需要将 TXT 放到正确目录结构（g###/ 子目录）
python3 batch_tpms_inp.py \
    --wfc-2d-batch ./wfc_2d_output \
    --wfc-3d-batch ./wfc_3d_output \
    --out-2d ./batch_inp_2d \
    --out-3d ./batch_inp_3d
```

或者分步：
```bash
# 仅 2D
python3 batch_tpms_inp.py --only-2d
# 仅 3D
python3 batch_tpms_inp.py --only-3d
```

### 五、关键注意事项

1. **`batch_tpms_inp.py` 搜索 TXT 文件的模式**: 默认在 `--wfc-2d-batch` 下搜索 `encode2d*.txt`，在 `--wfc-3d-batch` 下搜索 `encode3d*.txt`。文件名必须匹配这些模式。

2. **TXT 文件目录结构**: `batch_tpms_inp.py` 要求 TXT 在 `g###/` 子目录中（如 `g000/encode3d_xxx.txt`），否则 `strict_g_folder` 为 True 时会跳过。

3. **`batch_tpms_inp.py` 的默认输入路径**: 
   - 2D: `../Virtual_Growth_Program_2D/generated/wfc_2d/MatTiles_programmability_batch`
   - 3D: `../Virtual_Growth_Program_2D/generated/wfc_3d/OrthoFig6B_batch`
   如果目录不存在需传 `--wfc-2d-batch` 或 `--wfc-3d-batch` 覆盖。

4. **Gmsh 是 3D 必要的**: `--mode 3d` 生成 `tpms_3d_smooth_solid.inp` 需要 Gmsh 对 STL 做四面体剖分。没有 Gmsh 时平滑固体 INP 不生成。

5. **2D CDT 需要 `triangle` 库**: pip install triangle。

6. **输出文件名差异**: `generate_ortho_tile_inp_catalog.py` (3D catalog) 直接复制 `tpms_3d_smooth_solid.inp` 重命名为 `{tile_name}.inp`。`batch_tpms_inp.py` (3D batch) 也复制 `tpms_3d_smooth_solid.inp`，但重命名为 `g{tag_g:03d}_s{tag_s:03d}_tpms_3d.inp`。
